# Operations runbook (not public)

The project's operations runbook is kept private. It holds the production procedures (incidents and recovery, data
repairs, deploys, rollback and break-glass, switch changes) and identifiers the project does not publish.

Comments and READMEs in this repository still cite it, as `docs/RUNBOOK.md` with a section number, or as
`RUNBOOK 14.2`. Those section numbers refer to the private copy; see the glossary in [README.md](README.md). The code
next to such a reference is meant to stand on its own. If it does not, open an issue.

What is public:

- [DEPLOYING.md](DEPLOYING.md): how a change reaches production, and what the deploy workflow checks on the way.
- [SECURITY.md](../SECURITY.md): how to report a vulnerability.
